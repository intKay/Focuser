# 发布与验收清单

当前构建、测试与数据边界记录见本机 `outputs/screen_time/distribution/verification.json`。该证据含本机运行信息，不随公开源码包发布。

发布候选版要求：

- Python与JS回归通过；用量、bonus、验证门槛、目录锁与损坏数据检查通过。
- 独立端口与独立数据的控制台、扩展连接、用途隔离、配额耗尽及离线拦截验收。
- wheel在干净虚拟环境安装、从项目目录外启动、加载网页与下载扩展。
- 发布包不含outputs/migration/state/备份/浏览器配置；压缩包校验值完整。
- 本机真实服务继续保持原有当日用量与记录；不消耗真实分钟。

正式稳定版还需：

- Windows10/11、macOS与Linux干净机器的安装、升级、登录启动、睡眠/唤醒和时区切换测试。
- Chrome/Edge/Firefox及声明支持的Chromium浏览器实际安装与完整一分钟、隐私窗口、关服与重启测试。
- Firefox签名/商店审核，Chrome商店或明确的开发者模式分发说明；真实安装程序签名按分发渠道准备。
- 连续运行与异常断电恢复测试。新增macOS/Linux桌面拦截需单独实现并验收。

只公开distribution下的源码ZIP、扩展ZIP、wheel与SHA256SUMS；不要上传整个项目目录。测试日志、截图、安装环境、迁移历史属于本地开发证据。
