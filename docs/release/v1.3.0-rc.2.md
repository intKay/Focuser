# Focuser v1.3.0-rc.2 — Intentional screen time / 有意识地使用屏幕

Free, open-source screen-time budgets that stay on your computer. This is the first public **prerelease**, with English and Simplified Chinese interfaces and a simpler installation flow.

免费开源、数据留在本机的屏幕时间工具。这是首个公开**预发布候选版**，提供中英文界面与简化安装流程。

## Install / 安装

Download `focuser-local-1.3.0rc2-source.zip`, extract it to a permanent folder, and run:

下载源码 ZIP，解压到固定目录，运行：

```sh
# First-time users only / 仅首次使用
python install.py --new-install          # Windows
python3 install.py --new-install         # Fedora / Linux / macOS
```

Python 3.10+ is required. Fedora: `sudo dnf install python3 python3-pip`. The installer creates an isolated environment, configures login startup and opens the local dashboard. Then load the browser extension following **Connect & settings**. Browser extension installation remains a manual browser step.

需要 Python 3.10+。安装器创建独立环境、配置登录启动并打开本机控制页；然后按“连接与设置”载入扩展。最后一步仍需在浏览器中手动完成。

**Existing users / 已有用户：** back up and retain the complete original private data directory, use `--data-dir /path/to/existing-data`, and omit `--new-install`. Never upload state or backups to GitHub. 先备份并保留原数据，不通过新安装重置额度，不上传状态或备份。

## Highlights / 更新

- English/Chinese dashboard, intention prompts, block pages and verification UI; automatic selection and manual language switch.
- Shared category budgets, weekday schedules, downtime, private intention checks and the existing one-action integral gate.
- Fedora/systemd, macOS/launchd and Windows hidden-login setup. Unsupported migrated native rules are refused.
- Bilingual README and installation guides; screenshots contain synthetic data only.
- 中英文控制台、用途确认、拦截和验证 UI，支持自动选择与手动切换。
- 分类共享额度、星期额度、停用时段与原有操作绑定验证；不保存用途。
- 统一各平台登录启动配置；迁移不静默放宽不兼容规则。
- 中英文文档与纯模拟数据截图。

## Known limits / 已知限制

- Native app enforcement is Windows-only. Fedora/Linux/macOS support website limits; real desktop acceptance is still needed.
- Firefox is unsigned and temporary: reload after every browser restart.
- No Android/iOS/Safari support, automatic cross-device sync, signed executable installer or administrator-proof enforcement.
- Windows 原生 App 限制之外的平台目前仅限制网站；Fedora 仍需实机验收。
- Firefox 重启后需重新加载；没有移动端、Safari、跨设备自动同步或独立签名安装程序。
